# ShowFinder

ShowFinder is a React Native mobile app that allows users to search for TV shows, browse results, and view show details using the TVmaze API.

## Course
SODV2205 — Mobile Application Development with React Native I

## Developer
Asen Georgiev — Individual project. Responsible for planning, design, development, testing, and documentation.

## Target Users
People who want a simple way to find information about television shows.

## Planned Features
- Search for TV shows by title.
- Browse results with posters and basic information.
- View a show's description, genres, language, rating, and status.
- Display loading indicators, error messages, and empty results.

## Planned Screens
1. **Search:** Enter a TV show title and submit a search.
2. **Results:** Browse matching shows in a scrollable list.
3. **Details:** View expanded information about a selected show.

## Technology
- React Native with Expo
- Axios with async/await for API requests
- React Navigation for screen navigation
- React Hooks for state and API logic
- FlatList for search results
- Reusable UI components
- Flexbox and StyleSheet for layouts
- Expo Vector Icons

## API
[TVmaze API](https://www.tvmaze.com/api)

Show information and images will come from the live API. The app will not use a database or persistent local storage.
